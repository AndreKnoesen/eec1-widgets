Background: Key Concepts for This Lab

Review before starting Problem 1

Filename convention. Every .mat file in the class dataset uses this pattern: activity_firstname_lastname_section.mat Examples: walk_jane_smith_a03.mat · run_john_doe_b01.mat · jump_ali_hassan_b02.mat The activity name is always the first word, before the first underscore.

What each file contains. Each .mat file holds one variable data — an N×4 matrix with columns [Ax, Ay, Az, t]. This is the same format as the synthetic files in Lecture 12 Activity 2.

Structures are passed by value. When you pass a struct to a function, the function receives a copy. Modifications to that copy are discarded when the function returns — unless the function returns the modified struct and the caller assigns it back. s = myFunc(s) is the correct pattern; myFunc(s) alone changes nothing in the caller’s workspace.

[results.field] extraction. Given a struct array where every record has a scalar field peak, the expression [results.peak] produces a 1×N row vector — one value per record. This only works when the field is a scalar (not an array) in every record.

Problem 3 — buildResults (20 points)

Filename: buildResults.m

Write a function that processes a full set of .mat files and returns an array of structures — one record per file. Include computeRecord and getActivity as local functions.

function results = buildResults(filenames, threshold)
% Loads and processes a set of .mat files into a struct array.
%
% Inputs:
%   filenames - 1xN  string array  .mat filenames to load
%   threshold - 1x1  double        event detection threshold (m/s^2)
%
% Outputs:
%   results - 1xN  struct array  one record per file
%             Fields: .filename, .activity, .peak, .num_events, .duration
%
% Each .mat file must contain a variable named 'data' (Nx4 matrix [Ax Ay Az t]).

    for i = 1:length(filenames)
        loaded = load(filenames(i));
        data   = loaded.data;
        results(i) = computeRecord(data, filenames(i), threshold);
    end

end
