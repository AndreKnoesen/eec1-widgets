This lecture introduces App Designer for building interactive GUIs, with applications to mapping/GPS visualization and game-style interfaces.

1. Mapping and GPS Visualization in App Designer

  • Introduction to App Designer components
  • Using UIAxes for map-style plotting
  • Plotting multiple points and routes
  • Simulating a moving GPS point
  • In-class practice activity

2. GUI Components for Game Development

  • Common components for games:
    • Buttons
    • Tables
    • Image components
  • Organizing app layouts

3. Importing Images and GIFs

  • Adding images to App Designer
  • Displaying PNG / JPG files
  • Using animated GIFs in apps
  • Simple visual customization tips

4. Live Demonstration and Student Practice

  • Building a small interactive GUI
  • Testing callbacks and live updates
  • Questions and troubleshooting
