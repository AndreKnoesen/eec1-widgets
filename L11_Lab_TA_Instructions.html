L11 Lab — TA Instructions: Group Project Data Collection

ENG 6 Spring 2026 | Instructor/TA Use Only Time budget: 30 minutes

What This Lab Accomplishes

Each student runs a MATLAB script that records 20 seconds of smartphone accelerometer data for three activities (walking, running, jumping) and saves three .mat files named with their identity:

walk_jane_smith_a03.mat
run_jane_smith_a03.mat
jump_jane_smith_a03.mat

Students submit all three files to a Canvas assignment. After all lab sections close, you download the submissions, run a two-step MATLAB script that extracts and renames the files and generates class_files.m, then post class_files.m so every student can run their batch analysis loop on the full class dataset.

Before Lab (Day Before or Morning Of)

1. Create the Canvas submission assignment. - Go to Canvas → Assignments → + Assignment - Title: L11 Lab Sensor Data - Submission type: File Uploads — set allowed extensions to .mat only - No due-date penalty (accept until midnight after the last lab section) - Do not grade here — completeness is tracked via the gradebook checkmark

2. Know the lab section codes. Post the official section codes on the board or projector at the start of lab (e.g., A01, B02). The script lowercases everything and strips spaces, but confirm students enter the section code consistently — a typo creates a file that is hard to attribute later.

3. Have a backup dataset ready. If phones fail, use the synthetic files from the L11 cheat sheet generator. Keep walk.mat, run.mat, jump.mat available. These are last resort only — real student data is the goal.

4. Confirm the script is accessible. The script is publicly available at:

https://aknoesen.github.io/eec1-widgets/L11_Lab_DataCollection.m

Post this websave command in the course chat at the start of lab:

websave("L11_Lab_DataCollection.m", "https://aknoesen.github.io/eec1-widgets/L11_Lab_DataCollection.m");

During Lab — 30-Minute Timeline

Time What’s happening
0–3 min Distribute student instruction sheet. Students open MATLAB Online. Post the Canvas assignment link and lab section codes on the projector.
3–8 min Students connect their phone to MATLAB Mobile and run the setup steps. Circulate — most connection failures are Wi-Fi (phone and laptop must be on the same network).
8–25 min Students run the script. Each of the three 20-second recordings runs back-to-back with an Enter prompt between them. Total active script time is ~5 minutes.
25–30 min Students submit their three files to Canvas. Confirm by opening Canvas → Grades for your section — submitted students show a file icon.

Circulating: What to Watch For

Phone not connecting: - Check that MATLAB Mobile is open and logged into the same MathWorks account as the MATLAB Online session - Both devices must be on the same Wi-Fi network — eduroam is fine; hotspots sometimes block the connection - If connection fails after 2 minutes, pair that student with a teammate who has a working connection — one phone per team is sufficient

Script warning “No data received”: - Usually means m.Logging = 1 fired before the phone fully connected - Tell the student to re-run the script from the beginning: clc; L11_Lab_DataCollection

Student entered inconsistent name/section: - The script lowercases everything and strips spaces before saving - If a file arrives with a garbled name (visible in Canvas), note the student’s name and rename the file yourself when processing the full dataset — do not ask the student to re-collect

Student finishes early: - Have them verify Canvas shows “Submitted” with three files listed - Or: run a second collection (different walking speed or jumping height) and save with _v2 appended — useful for variability analysis in the Group Project

Monitoring Submission Completeness

  2. Find the L11 Lab Sensor Data column
  3. Any student without a file icon has not submitted — send one targeted reminder

At the end of your lab section, screenshot or export the gradebook column. This is your record of who collected data.

Step 1 — Download All Submissions from Canvas

  1. Canvas → Assignments → L11 Lab Sensor Data → Download Submissions
  2. Save the ZIP to your computer and unzip it into a folder named canvas_downloads

Canvas prepends student identification to each filename (e.g., smith_jane_12345_walk_jane_smith_a03.mat). The next step strips the prefix automatically.

Step 2 — Extract and Rename Files, Generate class_files.m

Save this as process_submissions.m and run it once from the folder containing canvas_downloads:

% process_submissions.m
% Run from the folder that contains canvas_downloads/
% Produces: class_data/ (renamed .mat files) and class_files.m

source_dir = "canvas_downloads";
output_dir = "class_data";

if ~exist(output_dir, "dir"), mkdir(output_dir); end

d = dir(fullfile(source_dir, "*.mat"));
n_copied = 0;
skipped  = {};

for k = 1:length(d)
    raw   = string(d(k).name);
    parts = split(raw, "_");

    % Find where the original filename starts (walk / run / jump)
    start_idx = find(parts == "walk" | parts == "run" | parts == "jump", 1);

    if isempty(start_idx)
        skipped{end+1} = raw;
        continue
    end

    original = join(parts(start_idx:end), "_");
    src  = fullfile(source_dir, raw);
    dest = fullfile(output_dir, original);
    copyfile(src, dest);
    n_copied = n_copied + 1;
end

fprintf("Copied %d files to %s/\n", n_copied, output_dir);
if ~isempty(skipped)
    fprintf("WARNING — %d files skipped (unexpected naming):\n", length(skipped));
    for k = 1:length(skipped)
        fprintf("  %s\n", skipped{k});
    end
end

% Generate class_files.m
d2    = dir(fullfile(output_dir, "*.mat"));
names = string({d2.name});

fid = fopen("class_files.m", "w");
fprintf(fid, "files = [ ...\n");
for k = 1:length(names)
    if k < length(names)
        fprintf(fid, '    "%s", ...\n', names(k));
    else
        fprintf(fid, '    "%s"];\n', names(k));
    end
end
fclose(fid);

fprintf("Generated class_files.m  (%d files)\n", length(names));
fprintf("Expected: %d files (164 students × 3 activities)\n", 164*3);

After running: check that the file count is close to 492. The WARNING list identifies any files with unexpected naming — rename those manually.

Step 3 — Verify the Dataset

Run this quick sanity check in MATLAB:

run("class_files.m");
fprintf("%d files total\n", length(files));

% Count per activity
for act = ["walk", "run", "jump"]
    n = sum(contains(files, act + "_"));
    fprintf("  %s: %d\n", act, n);
end

Expected output:

492 files total
  walk: 164
  run:  164
  jump: 164

If any count is below 164, cross-reference with Canvas gradebook to identify who is missing, then send a targeted follow-up email.

Step 4 — Post class_files.m to the Course

  1. Upload class_files.m to Canvas → Files → Course Materials (or post as a Canvas Announcement attachment)
  2. Post in the course chat:

class_files.m is now available. Download it from Canvas Files and place it in your MATLAB working folder. Then run class_files in the Command Window — this defines the files variable your batch analysis loop needs. You do not need to paste 492 filenames by hand.
