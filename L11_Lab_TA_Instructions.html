L11 Lab — TA Instructions: Group Project Data Collection

ENG 6 Spring 2026 | Instructor/TA Use Only
Time budget: 30 minutes

What This Lab Accomplishes

Each student runs a MATLAB script that records 20 seconds of smartphone accelerometer data for three activities (walking, running, jumping) and saves three .mat files named with their identity:

walk_jane_smith_a03.mat
run_jane_smith_a03.mat
jump_jane_smith_a03.mat

All files are uploaded to a shared class folder. After the lab, you post the complete files array so every student can run their batch analysis loop on the full class dataset.

Before Lab (Day Before or Morning Of)

1. Create the shared upload folder.
Use MATLAB Drive — every student already has access through MATLAB Online.
- Create a folder: ENG6_Spring2026 / GroupProject / Lab_Data
- Set it to shared/collaborative so all students can upload
- Post the full path in the course chat at the start of lab, not before (avoids confusion)

2. Know the lab section codes.
Students enter their lab section when prompted by the script. Use the official section codes (e.g., A01, B02). Post these on the board or projector at the start of lab so students enter them consistently — a typo in the section code creates an unorganized file that's hard to attribute.

3. Have a backup dataset ready.
If phones fail, use the synthetic files from the L11 cheat sheet generator. Run it once before lab and keep walk.mat, run.mat, jump.mat available. These are last resort only — real student data is the goal.

4. Confirm the script is accessible.
The script is publicly available at:

https://aknoesen.github.io/eec1-widgets/L11_Lab_DataCollection.m

Students can download it directly in MATLAB Online using:

websave("L11_Lab_DataCollection.m", "https://aknoesen.github.io/eec1-widgets/L11_Lab_DataCollection.m");

Post this command in the course chat at the start of lab so students can paste it into the Command Window. No Canvas upload or MATLAB Drive sharing required.

During Lab — 30-Minute Timeline

During Lab — 30-Minute Timeline
Time What's happening
0–3 min Distribute student instruction sheet. Students open the script in MATLAB Online. Post the shared folder path and lab section codes on the projector.
3–8 min Students connect their phone to MATLAB Mobile and run the setup steps. Circulate — most connection failures are Wi-Fi (phone and laptop must be on the same network).
8–25 min Students run the script. Each of the three 20-second recordings runs back-to-back with an Enter prompt between them. Total active script time is ~5 minutes; most of the window is students reading the prompts and positioning themselves.
25–30 min Students upload their three files to the shared folder. Confirm uploads — check that files appear with the correct naming pattern before students leave.

Circulating: What to Watch For

Phone not connecting:
- Check that MATLAB Mobile is open and logged into the same MathWorks account as the MATLAB Online session
- Both devices must be on the same Wi-Fi network — eduroam is fine; hotspots sometimes block the connection
- If connection fails after 2 minutes, pair that student with a teammate who has a working connection — one phone per team is sufficient

Script warning "No data received":
- Usually means m.Logging = 1 fired before the phone fully connected
- Tell the student to re-run the script from the beginning (clc; L11_Lab_DataCollection)

Student enters inconsistent name/section:
- Common issue: spaces, capitalization, typos
- The script lowercases everything and strips spaces, but janesmith vs jane_smith would differ if they misread the prompt
- If a file arrives with a garbled name, rename it in the shared folder yourself — don't ask the student to re-collect

Student finishes early:
- Have them help a teammate with phone connection
- Or: run a second collection (e.g., different walking speed or jumping height) and save with _v2 appended — useful for variability analysis in the Group Project

After All Labs Conclude (by Monday)

Timeline note: Labs run Tuesday evening through Monday. Lecture 12 is Thursday — using synthetic data, not the class dataset. Do not post the class files array until all lab sections have uploaded. The class dataset is used in the homework, not in Lecture 12.

1. Collect the uploaded files.
After the final lab section on Monday, download all .mat files from the shared folder to a single local directory.

2. Generate the files array for the homework.
Run this in MATLAB to get a copy-pasteable string array from whatever was uploaded:

d = dir("path/to/shared/folder/*.mat");
names = string({d.name});
disp("""files = [" + join("""" + names + """", ", ") + "];""")

This prints a ready-made line students paste into their homework script.

3. Post before the homework is due.
Post the files array in the course chat. Students replace the three-file placeholder in their batch analysis script with this line. The loop body does not change — that is the point.

Example of what you will post:

files = ["walk_jane_smith_a03.mat", "run_jane_smith_a03.mat", ...
         "walk_omar_hassan_b01.mat", "run_omar_hassan_b01.mat", ...];

If the Lab Session Goes Short

If fewer than half the students have uploaded files by the end of lab:
- Use the synthetic backup dataset for L12 Activity 2
- Have students label their synthetic records with "Walk (synthetic)", "Run (synthetic)", etc.
- Real data can be collected outside lab and added to the Group Project folder later
